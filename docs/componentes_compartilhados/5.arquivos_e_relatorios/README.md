## 🎯 Visão Geral

Aqui tem os arquivos, que serão utilizados pelo sistema. Nesse caso existem alguns códigos JavaScript para uma funcionalidade de botão que eu peguei de outro estagiário, as logos e ícones do sistema e um documento .docx que serve de modelo para produzir um arquivo via APEX Office Print.

---

## Arquivos

- `botao.js` - Adiciona botões personalizados na barra de pesquisa de um relatório interativo. O botao.min.js é a mesma coisa, mas está comprimida.

- `icons/app-icon` - São ícones de variados tamanhos e formatos feitos automaticamente quando eu coloquei em /Interface do Usuário/Atributos da Interface do Usuário/Ícone um ícone do SF.

- `icons/logo` - São logos do SF que eu utilizo na minha página global (0) para montar o header.

- `template_os.docx` - Um modelo para servir de base para o APEX Office Print para produzir um documento.
